# Automation Lab Academy 12.1 — мобильная версия

Открывается в браузере телефона, адаптирована под вертикальный экран. Содержит прежние 9 направлений, 1350 уроков и 494 лабораторные из версии 12.0. Улучшены меню, нижняя навигация, ввод числовых ответов, чтение длинных уроков и элементы управления.

## Открыть на телефоне

Самый простой способ — опубликовать содержимое этой папки на GitHub Pages / Cloudflare Pages (через HTTPS), открыть ссылку с телефона. На Android в Chrome: меню → «Установить приложение» или «Добавить на главный экран». На iPhone в Safari: «Поделиться» → «На экран Домой».

После **первой полной загрузки при подключённом интернете** PWA будет сохранять основные файлы для последующего офлайн-доступа. Для сохранения прогресса используется хранилище браузера; удаление данных сайта, изменение адреса или переход на другой браузер может его удалить. Делайте экспорт JSON в настройках.

Если просто открыть index.html с телефона как файл, PWA-установка и кэширование сервис-воркера не гарантируются; для PWA требуется HTTPS (или localhost на компьютере). На компьютере можно также открыть index.html напрямую, как раньше.

Установка на экран телефона не является нативным APK/IPA-приложением и не синхронизирует прогресс между устройствами. Данная редакция основана на версии 12.0 без облачных аккаунтов.
